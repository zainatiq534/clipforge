# Editor layout skeleton (Lykhaari positions · ClipForge colors)

```
title    title     title
tabs     tabs      preview
work     inspect   preview
time     time      preview
```

- **preview** spans from the tabs row to the bottom (video + player).
- **inspector** holds Media (shorts) and selection edits.
- **timeline** sits under work + inspector.
- Colors stay ClipForge light (violet / white) via `editor-layout.css`.
